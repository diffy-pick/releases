# DiffyPick Releases

DiffyPick — MySQL / MariaDB / PostgreSQL / SQL Server / SQLite 対応のスキーマ差分・同期デスクトップアプリ — の配布専用リポジトリです。

- **ダウンロード**: [Releases](../../releases) ページから最新版を取得してください
- アプリの自動アップデートも本リポジトリの Releases を参照します
- ソースコードは非公開です (closed-source 商用アプリ)

## リリースページの「Source code」 リンクについて

GitHub の各 release には仕様上自動で「Source code (zip)」 / 「Source code (tar.gz)」 リンクが付与されますが、 これは**本リポジトリ (`diffy-pick/releases`) の内容 (= 実質この README.md のみ) を tarball 化したもの**であり、 **DiffyPick 本体のソースコードは含まれません**。 本体は closed-source で、 ソースは公開・配布されていません。 実際のアプリのダウンロードは各 release の `DiffyPick-*.dmg` / `DiffyPick-*.exe` / `DiffyPick-*.AppImage` 等のバイナリ資産を使用してください。

---

This repository hosts release binaries and the auto-update feed for DiffyPick, a desktop GUI for diffing and syncing schemas across MySQL, MariaDB, PostgreSQL, SQL Server, and SQLite. The source code is closed. Download the latest version from the [Releases](../../releases) page.

**About the "Source code" links on release pages**: GitHub automatically attaches "Source code (zip/tar.gz)" archives to every release. These archives contain only this repository's contents (essentially just this README.md) — **the actual DiffyPick source code is closed and not included**. Please use the binary assets (`DiffyPick-*.dmg` / `DiffyPick-*.exe` / `DiffyPick-*.AppImage` etc.) to install the app.
